🚗 Star Protect Vehicle System (Java Console Application)

Star Protect Vehicle System is a Java-based console application that simulates an insurance management system for vehicle protection. The project focuses on Admin and Underwriter roles with proper authentication and data management using Java Collections (HashMap).

🔑 Key Features
Admin Login with secure credentials
Underwriter Management
Add Underwriter (auto-generated ID)
Remove Underwriter
View all Underwriters
Search Underwriter by ID
Update Underwriter password with validation
Underwriter Login
Password validation with special characters
Menu-driven, user-friendly console interface

🛠️ Technologies Used
Java
OOP Concepts (Classes, Objects, Encapsulation)
HashMap for data storage
Scanner for user input

🎯 Purpose

This project is designed for learning and practicing core Java concepts, role-based access control, and basic system design. It is suitable for MCA students and beginners in Java application development.
